# 1. Overview

The AML Coherence Model defines how AML systems evaluate:
- continuity
- cognitive stability
- semantic alignment
- restoration flow
- runtime consistency
- emotional regulation impact

Coherence is treated as a measurable system property.

---

# 2. Core Principle

A coherent system preserves alignment between:
- meaning
- rendering
- behavior
- interaction
- cognition
- emotional tone

Fragmentation reduces coherence.

Restoration increases coherence.

---

# 3. Definition of Coherence

In AML:

Coherence is the degree to which a system remains:
- understandable
- stable
- semantically aligned
- emotionally non-fragmenting
- cognitively sustainable

during interaction.
