## The 60-second version

AI systems increasingly generate what people see on screen. Existing frontend technology can render that output beautifully, but it does not inherently expose the machine's declared purpose, governing policy, authority, or evidence trail.

ĀML explores a new layer between machine intent and the human interface. The project calls this an **AI Interface Firewall™**. It can inspect meaning, apply policy, decide whether an interface element should render, and generate receipts and provenance that can be examined later.

The reference implementation is public and includes a parser, policy engine, semantic structures, cryptographic verification, provenance, protocol/RFC work, browser demos, HTML bridges, GitHub integration, View Meaning™, and enterprise evaluation material.

ĀML is a working research prototype and evolving specification. It is not presented as a ratified web standard or a scientifically complete model of human attention.

## Copy-ready security post

Security teams already ask who executed an action, what authority they had, and whether the event can be audited. AI-generated interfaces deserve similar scrutiny.

ĀML — ĀRU Meaning Language is experimenting with policy enforcement, provenance, signed execution receipts, replay protection, authorization/revocation, trust delegation, and independent verification at the interface layer.

It is not a replacement for application security. It is an attempt to make machine-generated UI decisions more inspectable and verifiable.
