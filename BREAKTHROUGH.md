# BREAKTHROUGH — EthicalRenderGate

## The Core Idea Behind ĀML

Traditional interface systems ask:

> Can this render?

ĀML asks:

> Should this render?

This changes rendering from a purely technical process into an accountable semantic process.

---

# The Breakthrough Equation

```aml
render_allowed = restoration_value >= attention_cost
```

Every interface element must justify the attention it consumes.

If an element consumes more cognitive energy than the value it restores, AML can:

- suppress it
- degrade it
- replace it
- reroute it
- log its failure state

This is called:

# EthicalRenderGate

---

# Why This Matters

Modern systems optimize for:

- clicks
- engagement
- retention
- compulsion
- stimulation

But no dominant rendering system evaluates:

- cognitive burden
- restoration
- clarity
- long-term user wellbeing
- semantic integrity

AML introduces rendering accountability.

---

# The Shift

## HTML

```text
If it exists → render it
```

## AML

```text
If it harms more than it restores → do not fully render it
```

This is the transition from:

- passive rendering
to
- ethical rendering

---

# Render States

AML supports multiple rendering outcomes.

| State | Meaning |
|---|---|
| allowed | element fully renders |
| degraded | partial rendering |
| suppressed | blocked entirely |
| fallback | rerouted safer version |
| mirrored | reflective semantic state |

---

# Example

An interface element with:

```text
attention_cost = 9
restoration_value = 2
```

would fail EthicalRenderGate.

AML may suppress or degrade the element automatically.

Traditional HTML would still render it normally.

---

# render_decision.json

AML outputs transparent rendering decisions.

```json
{
  "element": "engagement_trap",
  "attention_cost": 9,
  "restoration_value": 2,
  "render_allowed": false,
  "rendering_mode": "suppressed"
}
```

Rendering becomes observable and accountable.
