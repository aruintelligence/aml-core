# Security Policy

## Reporting Vulnerabilities

If you discover a vulnerability, exploit pathway, ethical bypass, or rendering manipulation issue within ĀML, please report it responsibly.

Do not publicly disclose vulnerabilities before remediation discussion.

---

# Scope

Security concerns include:
- EthicalRenderGate bypass attempts
- falsified restoration scoring
- attention-cost manipulation
- render decision spoofing
- audit log tampering
- runtime injection vulnerabilities
- compiler-level execution exploits

---

# Responsible Disclosure

Please include:
- reproduction steps
- affected files
- expected behavior
- actual behavior
- screenshots or logs if available

---

# Philosophy

ĀML treats ethical rendering integrity as part of system security itself.

Manipulating restoration metrics is considered a core infrastructure concern.
