# Support

ĀML is a working research prototype stewarded by ĀRU Intelligence Inc. This page explains how to get help. It is not a paid support contract and does not declare a formal service-level agreement.

## Documentation

Start here:

- [README.md](README.md) — what ĀML is, how to run tests, and current status
- [docs/README.md](docs/README.md) — documentation index
- [docs/CONSUMER_QUICKSTART.md](docs/CONSUMER_QUICKSTART.md) — installed-package quickstart

- [support-policy.json](support-policy.json) — machine-readable stable and preview channel policy

The stable package/CLI/capability contract remains `v1.3.0`. The current GitHub prerelease snapshot is `v1.4.0-rc.2`. No long-running support channel beyond those published channels has been approved.

## Questions, bugs, and feature requests

Please use [GitHub Issues](https://github.com/aruintelligence/aml-core/issues) for public bugs, documentation gaps, and feature requests. Issue forms are available under [New issue](https://github.com/aruintelligence/aml-core/issues/new/choose).

When you file a bug, include:

- the exact commit or tag;
- Node.js, Python, or Go versions, as relevant;
- the shortest command or fixture that reproduces the result;
- expected behavior and actual behavior.

Pull requests are welcome. See [CONTRIBUTING.md](CONTRIBUTING.md) and the [Code of Conduct](CODE_OF_CONDUCT.md).

## Security issues

Do not file a public issue for a potentially exploitable vulnerability. Follow [SECURITY.md](SECURITY.md) and email **Office@aruintelligence.com** until GitHub private vulnerability reporting is enabled.
