# ĀML Language Specification
## Version 1.0 Draft

---

# 1. Overview

ĀML (ĀRU Meaning Language) is a meaning-native interface language designed to introduce:
- ethical rendering
- accountable execution
- restoration-aware interfaces
- semantic runtime evaluation
- attention-conscious computation

ĀML compiles into:
- HTML
- CSS
- JavaScript
- memory metadata
- render accountability objects

---

# 2. Core Design Goals

The language is designed to prioritize:
- clarity
- inspectability
- semantic readability
- restoration-first rendering
- deterministic behavior
- explicit meaning declaration
