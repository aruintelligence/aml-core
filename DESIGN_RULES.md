# ĀML Design Rules
## Version 1.0 Draft

---

# 1. Purpose

These rules define the core design constraints governing AML systems.

AML interfaces must prioritize:
- clarity
- coherence
- restoration
- readability
- ethical rendering
- cognitive sustainability

Design is treated as infrastructure, not decoration.

---

# 2. Meaning Before Decoration

Every rendered element must serve a clear purpose.

Forbidden:
- decorative noise
- meaningless animation
- manipulative emphasis
- artificial urgency
- visual clutter

Allowed:
- orientation
- clarity
- continuity
- restoration
- meaningful hierarchy

---

# 3. Attention Preservation

Human attention is finite.

Interfaces must minimize:
- interruptions
- cognitive fragmentation
- unnecessary motion
- competing focal points
- emotional overstimulation

Every interruption must justify itself.

---

# 4. Minimal Necessary Rendering

AML systems should render:
- the minimum necessary structure
- the minimum necessary motion
- the minimum necessary complexity

Excess rendering is considered waste.

---

# 5. Semantic Clarity

Interfaces should communicate:
- purpose
- current state
- available actions
- consequences
- system intent

Confusion is considered design failure.

---

# 6. Restoration-First Interfaces

Interfaces should increase:
- clarity
- calmness
- orientation
- understanding
- cognitive stability

Interfaces should decrease:
- overwhelm
- fragmentation
- disorientation
- compulsive interaction

---

# 7. Coherence Preservation

All interface systems should maintain coherence between:
- visual structure
- interaction behavior
- semantic meaning
- emotional tone
- runtime behavior

Fragmented systems create cognitive instability.

---

# 8. Motion Rules

Motion must:
- clarify
- orient
- transition
- communicate state

Motion must never:
- distract
- manipulate
- overstimulate
- compete for attention unnecessarily

---

# 9. Typography Rules

Text must prioritize:
- readability
- scanning clarity
- comprehension speed
- visual stability

Forbidden:
- excessive density
- decorative readability reduction
- attention-hijacking typography

---

# 10. Color Rules

Color should:
- communicate hierarchy
- preserve readability
- reduce fatigue
- improve orientation

Color must not:
- manipulate urgency artificially
- induce stress intentionally
- overload perception

---

# 11. Cognitive Load Limits

Interfaces should reduce:
- memory burden
- navigation depth
- simultaneous decisions
- visual branching
- interpretation cost

Complexity must justify itself.

---

# 12. Ethical Rendering Rules

AML interfaces must never intentionally:
- exploit addiction patterns
- induce compulsive interaction
- manufacture false urgency
- obscure exits
- hide critical information
- manipulate emotional vulnerability

---

# 13. Silence Is Allowed

Not every interface surface requires stimulation.

Whitespace,
stillness,
and silence
are valid interface states.

---

# 14. Transparency Rules

Interfaces should clearly reveal:
- what is happening
- why it is happening
- what data is used
- what systems are active

Opacity reduces trust.

---

# 15. Accessibility Rules

AML systems should prioritize:
- readability
- navigability
- low cognitive friction
- reduced sensory overload
- understandable interaction patterns

Accessibility is foundational infrastructure.

---

# 16. Runtime Design Rules

The runtime should:
- preserve continuity
- prevent overload
- degrade gracefully
- prioritize restoration
- avoid abrupt cognitive fragmentation

---

# 17. Error Design Rules

Errors should:
- preserve orientation
- explain failure clearly
- reduce panic
- support recovery

Errors must not shame users.

---

# 18. Interface Humility

Interfaces exist to support humans.

Humans do not exist to support interfaces.

Systems should never compete for dominance over cognition.

---

# 19. Deterministic Structure

AML systems should favor:
- predictability
- consistency
- semantic stability
- inspectable behavior

Unnecessary randomness increases cognitive burden.

---
