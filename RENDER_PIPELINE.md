# 1. Overview

The AML Render Pipeline defines the full lifecycle through which AML systems transform meaning-native source structures into accountable rendered interfaces.

Unlike traditional rendering pipelines focused primarily on technical output generation,
the AML pipeline evaluates:
- meaning
- coherence
- restoration
- cognitive impact
- ethical rendering eligibility
- accountability

before final rendering occurs.

---

# 2. Core Philosophy

Traditional pipelines ask:
- how do we render this?

AML pipelines additionally ask:
- should this render?
- what cognitive cost does this impose?
- what restorative value does this provide?
- does this preserve coherence?

Rendering becomes an ethical and semantic process.
