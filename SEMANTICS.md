# 1. Overview

The AML Semantic Model defines how meaning is represented,
preserved,
interpreted,
and propagated throughout AML systems.

Traditional systems prioritize:
- syntax
- execution order
- structural correctness

AML additionally prioritizes:
- semantic continuity
- meaning preservation
- contextual integrity
- ethical intent
- restoration purpose

Meaning becomes part of executable infrastructure.

---

# 2. Core Principle

Execution without preserved meaning creates semantic collapse.

AML systems therefore preserve:
- intention
- context
- purpose
- restoration metadata
- coherence relationships

throughout the compiler and runtime lifecycle.

---

# 3. Semantic Definition

In AML,
semantics refers to:
- what a structure means
- why it exists
- what effect it intends
- what restoration purpose it serves
- how it affects cognition

Semantics are treated as first-class system structures.
