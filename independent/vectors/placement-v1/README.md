# Frozen placement assessment v1

`placement.json` declares three **fictional** sites, infrastructure systems, and custodians for the existing shard vector. `expected.json` is the deterministic assessment: nine single-domain failures each leave a trusted recovery pair. This is test data, not evidence that any physical copies exist.

The cross-runtime check compares the full JavaScript and independent Python reports, then repeats the assessment with a shared site and custodian, missing accepted head, damaged share, and invalid manifest.
