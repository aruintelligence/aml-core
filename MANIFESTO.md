# The ĀML Manifesto

The internet became a battlefield for attention.

Every pixel fights.
Every notification interrupts.
Every animation competes.
Every platform extracts.

Human attention became the product.

ĀML rejects this direction.

---

# We Believe

Interfaces should protect cognition, not fragment it.

Software should restore clarity, not manufacture dependency.

Rendering should require justification.

Attention is sacred infrastructure.

---

# We Reject

- manipulative dark patterns
- infinite distraction loops
- interruption-driven UX
- meaningless engagement metrics
- cognitive overload as business strategy

---

# We Build

- ethical rendering systems
- coherence-aware interfaces
- restoration-first computing
- transparent render accountability
- meaning-native software
