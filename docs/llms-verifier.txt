Implementation claims:
Use aml-verifier-implementation-claim/1 to declare exactly which immutable contract snapshot your verifier targets. A claim is not proof of conformance.

Generate a claim:
node scripts/create-verifier-implementation-claim.mjs --implementation-id my-verifier --implementation-version 0.1.0 --runtime rust-1.90 --source-url https://github.com/example/my-verifier --command './my-verifier --now 2030-01-01T00:05:00Z bundle.json' --external true
