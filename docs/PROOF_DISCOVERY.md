# ĀML proof discovery

**Status: SHIPPED reference-project surface / SPEC for broader convention**

ĀML proof should be discoverable by people, search engines, and tooling without scraping prose.

Reference-project discovery surfaces:

- Human proof: https://aruintelligence.github.io/aml-core/proof.html
- Embeddable proof: https://aruintelligence.github.io/aml-core/proof-card.html
- Decision gallery: https://aruintelligence.github.io/aml-core/gallery.html
- Machine proof manifest: https://aruintelligence.github.io/aml-core/proof-manifest.json
- Machine proof links: https://aruintelligence.github.io/aml-core/proof-links.json
- Experimental discovery document: https://aruintelligence.github.io/aml-core/.well-known/aml.json
- View Meaning: https://aruintelligence.github.io/aml-core/view-meaning.html

The `.well-known/aml.json` path is an experiment in this reference deployment. It is **not** claimed as an IETF, WHATWG, W3C, or other ratified Internet convention.

A future independently implemented discovery convention should remain small enough that another runtime can publish equivalent URLs without importing this implementation.
