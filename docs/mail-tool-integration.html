HOST INTEGRATION

Use the complete mail wrapper for this schema.

The host supplies its intended recipient rule, approval flow, and mail service. The wrapper freezes arguments, maps the complete target, and returns a plan and receipt.

import { createMailGuardedToolExecute } from "./pilots/action-boundary/mail-guarded-tool.mjs";
import { mailTargetResource } from "./pilots/action-boundary/mail-target-manifest.mjs";

const intended = mailTargetResource({ to: "team@example.test" });
const policy = { protocol: "aml-action-policy/1", rules: [{
  tool: "send_message", effect: "send", resource: intended.resource,
  requires_approval: true
}] };
const execute = createMailGuardedToolExecute({
  purpose: "Send a team update", policy, requestApproval: hostApproval,
  consumeApproval: hostClaim, execute: hostMailCallback
});
