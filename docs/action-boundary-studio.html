Recheck it in Node

After downloading the bundle, run this command from the repository root. A consistent calculation exits zero; a mismatch exits nonzero.

node scripts/verify-action-studio-bundle.mjs aml-action-studio-bundle.json

Try the checked-in changed destination example or read the integration guide.

What the result means

  1. Exact route: zero matches denies, one matches, two matching rules deny as ambiguous.
  2. Approval: a matching rule can require a later host approval bound to the proposal digest.
  3. Consistency: the verifier checks this bundle against its own included policy. It cannot establish who authored that policy or whether any action occurred.
