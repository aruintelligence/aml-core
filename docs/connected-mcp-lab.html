Scope of the evidence.

The server only appends a temporary local audit line. This is a connected SDK pilot, not an external send, independent security assessment, general MCP interception, authenticated approval, or proof of provider delivery. A host must ensure every effectful call path uses its gate and bind the actual server/account and final provider request.

The deliberately unsafe comparison uses the same connected client but calls it directly. The server's annotation is untrusted metadata under the MCP specification. This demonstration does not claim a new protocol, independent validation, or an external delivery.
