How to reproduce it.
The Node runner calls the reference dispatchAction once per tool/effect/resource combination. A separately coded Python oracle checks all eight rows, including the canonical proposal digest, field bindings, receipts, and callback entries. CI also rejects deliberately false reports and reruns ten one-at-a-time source substitutions across three checked-in suites.
Run node pilots/action-boundary/policy-tuple.mjs --check, python3 pilots/action-boundary/verify_policy_tuple.py docs/action-policy-tuple.json, and node pilots/action-boundary/dispatch-mutants.mjs --check. Read the method and limits ↗
