Why this happens

The JavaScript reference sorts keys, rebuilds an ordinary object, then stringifies it. ECMAScript enumerates array-index keys numerically before other strings. The former Python code preserved a simple lexical sort. Keys such as "01" and "4294967295" are not array indices.

Read the ECMAScript property-order rule and Python JSON encoder behavior. ĀML follows its existing JavaScript wire bytes for this restricted contract; it does not claim a universal canonical JSON standard.
