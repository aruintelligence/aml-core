Run the black-box challenge

From the repository root, invoke the Python adapter as an executable process against all 13 public cases:

node scripts/run-action-boundary-challenge.mjs -- python3 pilots/action-boundary/challenge-python-adapter.py

The adapter imports no JavaScript boundary code and runs only simulated callbacks.

Check the visual report

Regenerate and compare the actual outputs of both implementations to this page’s checked-in data:

node scripts/build-action-cross-runtime-report.mjs --check

Supported wire subset: JSON integers in JavaScript’s safe range and BMP object keys. Other values fail closed in Python.
