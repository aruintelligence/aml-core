Exact declared tuple

The existing rule matches `tool`, `effect`, and `resource`. It does not inspect `arguments.to` or know a tool's real destination.

02 / BIND

Host derives the target

The wrapper snapshots the proposal and asks a trusted, tool-specific resolver for the destination in the frozen arguments. A missing, failed, or mismatched result blocks.

Content still needs a decision

An aligned recipient with a changed body can still pass an unreviewed rule. Hosts must enforce content requirements and separate approval where needed.
