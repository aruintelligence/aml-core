# ĀML en un minuto

**Estado: DRAFT — página localizada de prueba**

ĀML es un cortafuegos de interfaz entre la intención de una IA o aplicación y los píxeles.

Regla del prototipo:

```text
render_allowed = restoration_value >= attention_cost
```

Pruébalo:
https://aruintelligence.github.io/aml-core/playground.html

Cambia `restoration_value` para que sea menor que `attention_cost`, compila de nuevo e inspecciona la decisión.

Después abre View Meaning:
https://aruintelligence.github.io/aml-core/view-meaning.html

ĀML es un prototipo funcional, no un estándar global ratificado.
