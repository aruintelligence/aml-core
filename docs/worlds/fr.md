# ĀML en une minute

**Statut : DRAFT — page de preuve localisée**

ĀML est un pare-feu d’interface entre l’intention d’une IA/application et les pixels affichés.

Règle du prototype :

```text
render_allowed = restoration_value >= attention_cost
```

Essayez-le :
https://aruintelligence.github.io/aml-core/playground.html

Placez `restoration_value` sous `attention_cost`, compilez à nouveau et inspectez la décision.

Puis ouvrez View Meaning :
https://aruintelligence.github.io/aml-core/view-meaning.html

ĀML est un prototype fonctionnel, pas une norme mondiale ratifiée.
