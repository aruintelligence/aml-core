# ĀML em um minuto

**Status: DRAFT — página localizada de prova**

ĀML é um firewall de interface entre a intenção de uma IA/aplicativo e os pixels.

Regra do protótipo:

```text
render_allowed = restoration_value >= attention_cost
```

Teste:
https://aruintelligence.github.io/aml-core/playground.html

Altere `restoration_value` para ficar abaixo de `attention_cost`, compile novamente e inspecione a decisão.

Depois abra o View Meaning:
https://aruintelligence.github.io/aml-core/view-meaning.html

ĀML é um protótipo funcional, não um padrão global ratificado.
