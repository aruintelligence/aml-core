# एक मिनट में ĀML

**स्थिति: DRAFT — स्थानीयकृत प्रमाण पृष्ठ**

ĀML, AI/ऐप की मंशा और स्क्रीन पर दिखने वाले पिक्सेल के बीच एक इंटरफ़ेस फ़ायरवॉल है।

प्रोटोटाइप नियम:

```text
render_allowed = restoration_value >= attention_cost
```

इसे आज़माएँ:
https://aruintelligence.github.io/aml-core/playground.html

`restoration_value` को `attention_cost` से कम करें, फिर से कंपाइल करें और निर्णय देखें।

फिर View Meaning खोलें:
https://aruintelligence.github.io/aml-core/view-meaning.html

ĀML एक कार्यशील प्रोटोटाइप है, अनुमोदित वैश्विक मानक नहीं।
