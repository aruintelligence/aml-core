# ĀML in einer Minute

**Status: DRAFT — lokalisierte Beweisseite**

ĀML ist eine Interface-Firewall zwischen der Absicht einer KI/App und den angezeigten Pixeln.

Prototyp-Regel:

```text
render_allowed = restoration_value >= attention_cost
```

Jetzt testen:
https://aruintelligence.github.io/aml-core/playground.html

Setze `restoration_value` unter `attention_cost`, kompiliere erneut und prüfe die Entscheidung.

Öffne danach View Meaning:
https://aruintelligence.github.io/aml-core/view-meaning.html

ĀML ist ein funktionsfähiger Prototyp, kein ratifizierter globaler Standard.
