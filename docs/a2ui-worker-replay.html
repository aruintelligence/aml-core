The host boundary

Claim before the callback.

agent call ID→trusted session→exclusive claim→policy + approval→simulated callback

A duplicate in the same host session receives a correlated INVALID_FUNCTION_CALL before an AML dispatch receipt. A different trusted session may use that ID independently. The directory is provisioned by the host, retained for the full session lifetime, checked for ownership and permissions, and never silently recreated after loss.

Claim boundary. Simulated callback and approval. Local private filesystem only; not multi-machine coordination, authenticated user consent, or proof of delivery. The host must protect the directory from same-user tampering, authenticate its session identity and approval, and coordinate through a suitable durable store across machines. A new ID is a new attempt and still needs action authorization.
