A source hash answers “same bytes?”
A Meaning Fingerprint answers “same compiled AMT?”

ĀML compiles source into an Abstract Meaning Tree before fingerprinting it. That means lexical noise such as comments and formatting can disappear while meaning-bearing structure remains part of the authenticated material.

1 · Compile

Both sources run through the browser lexer, parser, and AMT builder.

2 · Canonicalize

The AMT is wrapped in domain-separated aml-meaning-material/1 and serialized with strict canonical JSON.

3 · SHA-256

The canonical UTF-8 bytes produce a deterministic aml-meaning-fingerprint/1 identity.

Put a Meaning Lock on CI.

If a pull request is supposed to be a meaning-preserving refactor, make the claim executable. This action exits nonzero when the compiled AMT fingerprint changes.

- uses: aruintelligence/aml-core/actions/meaning-lock@main
  with:
    before-file: before.aml
    after-file: after.aml

Or from the command line:

aml-meaning before.aml after.aml
Evidence boundary: matching fingerprints do not prove truth, ethics, human intent, subjective perception, or arbitrary program behavioral equivalence. They prove something narrower and reproducible: the two sources compiled to the same canonical ĀML AMT material under this versioned contract.
