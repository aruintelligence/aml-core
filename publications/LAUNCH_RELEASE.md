# Launch Release Draft — ĀML Interface Firewall Prototype

**Status: PITCH — publication-ready draft**

ĀRU Intelligence Inc. has published ĀML, a working research prototype for making AI- and app-generated interface decisions more inspectable before and after rendering.

ĀML sits between machine intent and human-facing pixels. In the reference prototype, interface elements can declare purpose, attention cost, and restoration value. A policy can decide whether the element is allowed to render, and the execution can produce a receipt that records the decision context.

The public project includes a browser proof, decision gallery, View Meaning inspector, Meaning Gate CI tooling, zero-install browser integration paths, deterministic replay tests, cross-runtime verification examples, public schemas, and an immutable verifier contract snapshot.

The fastest demonstration is available at:
https://aruintelligence.github.io/aml-core/proof.html

The source repository is:
https://github.com/aruintelligence/aml-core

ĀML is a research prototype, not a ratified global standard. Its attention/restoration values are declared/model inputs, not validated objective measures of human cognition or wellbeing.
