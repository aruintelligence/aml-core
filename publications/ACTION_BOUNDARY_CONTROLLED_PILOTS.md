## Reproduce

```sh
node scripts/build-controlled-pilot-pages.mjs --check-before
node scripts/dispatch-controlled-pilot-pages.mjs --check
node scripts/build-action-site-browser-receipts.mjs --check
node --test test/action-controlled-site-pilots.test.js test/action-site-browser-evidence.test.js
```

The verifier reads all 20 screenshots, 20 serialized DOM files, 20 browser-state JSON files, the ten host dispatch receipts, and the two pinned source commits. It recomputes every hash, checks the contact element remains identical, checks that exactly one target was removed in both source and browser DOM, and rejects a changed screenshot or DOM. It does not authenticate the browser operator or imply that a third-party website accepted the change.
