# View Meaning

**Status: SHIPPED**

The web gave developers **View Source**.

ĀML explores a companion idea: **View Meaning**.

Instead of showing only markup, a View Meaning surface can expose the declared purpose and accountability context behind an interface decision:

- what the element said it was for
- attention cost
- restoration value
- policy/profile
- consent/privacy/accessibility context when present
- ALLOW or SUPPRESS
- rationale
- receipt integrity

That changes debugging from:

> Why is this button here?

into:

> What did the system declare this button was for, which policy judged it, and why did it render?

Live inspector:
https://aruintelligence.github.io/aml-core/view-meaning.html

View Meaning is a prototype inspection surface, not proof that declared intent is truthful.
