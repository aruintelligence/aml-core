# Brief for AI Product Leaders

**Status: SHIPPED**

Generated UI creates a governance problem: models can alter user-facing flows faster than review systems built for static interfaces.

ĀML proposes a narrow control layer between model output and pixels.

What it can make inspectable:

- declared purpose
- attention cost
- restoration value
- policy decision
- receipt

The product value is not a magic ethics score. It is a **reviewable control point** for generated interfaces.

A practical pilot question:

> Can we put one generated UI region behind AML, compare ALLOW/SUPPRESS decisions, inspect receipts, and decide whether this improves review quality?
