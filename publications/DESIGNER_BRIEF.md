# Brief for Product and UX Designers

**Status: SHIPPED**

Design review usually inspects what users see. ĀML adds a second question:

> What did the system say this interface element was trying to do?

That creates a reviewable vocabulary around:

- purpose
- attention cost
- restoration value
- ALLOW / SUPPRESS
- receipt

This can make dark-pattern discussions more concrete because pressure is no longer only a visual impression; it can be represented as declared interface intent and tested against an explicit rule.
