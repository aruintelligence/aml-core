# Receipt Anatomy

**Status: SHIPPED**

An ĀML receipt exists to answer a simple question:

> What did the system declare, what decision was made, and what evidence can be inspected afterward?

A useful receipt can expose:

- declared purpose
- attention cost
- restoration value
- policy/profile used
- ALLOW or SUPPRESS result
- rationale
- output hash
- receipt integrity data

A receipt improves accountability because the decision is no longer only visible as final pixels.

It does **not** prove that the AI's declared purpose was truthful. It does not prove moral correctness. A signature or hash proves integrity of the bound data, not the goodness of the underlying policy.
