# ĀML Testing Specification
## Version 1.0 Draft

---

# 1. Overview

Testing in ĀML extends beyond traditional software correctness.

AML systems must validate:
- execution correctness
- semantic continuity
- ethical rendering behavior
- restoration integrity
- coherence preservation
- runtime accountability

A technically correct system that damages coherence is considered incomplete.

---

# 2. Testing Philosophy

Traditional testing asks:
- does the system work?

AML testing additionally asks:
- does the system preserve meaning?
- does the system preserve coherence?
- does the system justify attention consumption?
- does the system remain ethically accountable?
