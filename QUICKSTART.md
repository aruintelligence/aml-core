# ĀML Quickstart

## What Is ĀML?

ĀML (ĀRU Meaning Language) is a meaning-native interface language.

It is designed around one principle:

> Every element must justify the attention it consumes.

ĀML prioritizes:

- semantic clarity
- restoration
- ethical rendering
- cognitive coherence
- deterministic behavior
- minimal interface noise
