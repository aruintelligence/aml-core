# 1. Overview

This document defines the formal lexical and grammatical structure of ĀML.

The AML grammar is designed to prioritize:
- readability
- semantic clarity
- deterministic parsing
- low ambiguity
- minimal syntactic noise
- meaning preservation

The grammar favors explicit semantic structure over symbolic compression complexity.

---

# 2. Design Philosophy

AML syntax is designed to:
- read semantically
- remain visually stable
- minimize cognitive overhead
- preserve interpretability
- reduce unnecessary punctuation density

Syntax exists to support meaning,
not obscure it.
