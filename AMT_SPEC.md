# ĀML Abstract Meaning Tree Specification
## Version 1.0 Draft

---

# 1. Overview

The Abstract Meaning Tree (AMT) is the core semantic representation structure used by ĀML.

The AMT preserves:
- meaning
- intent
- ethical metadata
- coherence structures
- restoration context
- rendering relationships

throughout compilation and runtime evaluation.

Unlike traditional Abstract Syntax Trees (ASTs), which prioritize executable structure,
AMTs prioritize semantic continuity and interpretability.

---

# 2. Purpose

The AMT exists to:
- preserve meaning during compilation
- maintain ethical evaluation context
- support render accountability
- enable semantic inspection
- reduce contextual loss
- support restoration-aware execution

The AMT is the semantic spine of the AML ecosystem.

---

# 3. Core Philosophy

Traditional ASTs ask:
- how should this execute?

AMTs additionally ask:
- why does this exist?
- what meaning does it preserve?
- what effect does it produce?
- what restoration value does it create?

Meaning becomes part of the executable structure itself.

---

# 4. AMT Structure

An AMT is composed of semantic nodes.

Each node may contain:
- purpose
- semantic intent
- restoration metadata
- attention-cost metadata
- coherence relationships
- render eligibility context
