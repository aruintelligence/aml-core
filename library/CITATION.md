# Citing the ĀML Library

**Status: SHIPPED**

Each numbered library publication has a stable human-readable ID such as `AML-LIB-001` or `AML-CASE-002`.

Recommended citation pattern:

> Read, Daniel Jacob IV. “The Interface Firewall.” ĀML Library, AML-LIB-001, ĀRU Intelligence Inc., 2026. https://github.com/aruintelligence/aml-core/blob/main/library/AML-LIB-001-THE-INTERFACE-FIREWALL.md

For reproducibility-sensitive work, append the Git commit used by the citing project.

Example:

```text
AML-LIB-001 @ <git-commit-sha>
```

The stable library ID identifies the publication line. The Git commit identifies the exact historical text.

Do not cite a DRAFT casebook as evidence of industry adoption. Casebooks describe proposed applications unless independent evidence is explicitly linked.
