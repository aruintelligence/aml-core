# AML-CASE-006 — Education

**Status: DRAFT casebook built on SHIPPED AML primitives**

AI-assisted learning systems can generate explanations, quizzes, hints, reminders, recommendations, and engagement prompts at runtime.

## Candidate AML uses

- declare whether an element explains, assesses, reminds, or promotes
- keep useful learning actions separate from engagement pressure
- inspect generated prompts through View Meaning
- apply accessibility policies to generated learning UI
- preserve receipts for dynamically selected interventions
- compare semantic changes in tutoring prompts with Meaning Gate

ĀML does not measure whether a student learned, does not diagnose learning needs, and does not make pedagogical quality objective.

The narrower idea is that adaptive educational UI should be able to explain **why a particular interface intervention appeared** and preserve enough evidence for a teacher, developer, researcher, or learner to inspect the decision afterward.

This is a proposed application area, not evidence of education-sector adoption.
