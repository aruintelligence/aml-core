# ĀML — ĀRU Meaning Language

**Status: DRAFT**

## The interface firewall between AI intent and pixels.

AI can propose an interface. ĀML makes the declared purpose, attention cost, restoration value, policy decision, and receipt inspectable.

```text
render_allowed = restoration_value >= attention_cost
```

**Try it:** https://aruintelligence.github.io/aml-core/playground.html  
**View Meaning:** https://aruintelligence.github.io/aml-core/view-meaning.html  
**Code:** https://github.com/aruintelligence/aml-core

ĀML does not require replacing HTML or React. It can sit in front of existing UI as an interface firewall.

**Prototype status:** working research prototype; not a ratified global standard.
