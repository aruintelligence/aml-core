# ĀML proof with the network turned off

**Status: PITCH**

The core AML prototype decision can now be demonstrated from one self-contained HTML file.

No package install.
No CDN.
No framework.
No network after download.

File:
https://github.com/aruintelligence/aml-core/blob/main/docs/offline-proof.html

Live copy:
https://aruintelligence.github.io/aml-core/offline-proof.html

The file intentionally demonstrates only:

```text
render_allowed = restoration_value >= attention_cost
```

It does not pretend to contain the full compiler/runtime.

That makes it useful for classrooms, workshops, low-bandwidth environments, and skeptical reviewers who want the smallest possible reproduction.

Open the full demo. Change `restoration_value`. Screenshot the decision and receipt. File it.
