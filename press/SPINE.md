# ĀML Public Spine

**Status: SHIPPED**

## One sentence

ĀML is an **interface firewall** between AI/app intent and pixels: it makes declared purpose, attention cost, restoration value, policy decisions, and a receipt inspectable before and after rendering.

## One rule in the prototype

```text
render_allowed = restoration_value >= attention_cost
```

## One door

https://aruintelligence.github.io/aml-core/

## One proof path

1. Open the playground: https://aruintelligence.github.io/aml-core/playground.html
2. Change `restoration_value` below `attention_cost`.
3. Compile again.
4. Inspect the decision.
5. Open View Meaning: https://aruintelligence.github.io/aml-core/view-meaning.html
6. Inspect the receipt.

## One ask

Open the demo. Change `restoration_value`. Screenshot the decision and receipt. File what happened.
