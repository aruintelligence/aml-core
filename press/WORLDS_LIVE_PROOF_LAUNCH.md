# One ĀML proof, eight languages

**Status: PITCH**

The public AML proof is no longer English-only.

Use the same proof engine with language encoded in the URL:

- English: `?lang=en`
- Spanish: `?lang=es`
- Portuguese (Brazil): `?lang=pt-BR`
- Hindi: `?lang=hi`
- Arabic: `?lang=ar`
- Chinese: `?lang=zh`
- French: `?lang=fr`
- German: `?lang=de`

Arabic switches the live proof page to RTL.

The exact proof state can also carry the declared purpose and both score inputs:

```text
https://aruintelligence.github.io/aml-core/proof.html?lang=es&attention=5&restoration=1&purpose=Create%20urgency
```

The product claim does not change by language: ĀML is an interface firewall between AI/app intent and pixels.
