# CONTRIBUTING TO ĀML

Thank you for your interest in ĀML.

ĀML is an experimental meaning-native interface language exploring ethical rendering, accountable interfaces, and attention-aware computing systems.

---

# Project Status

ĀML is currently an early-stage public prototype.

Core systems under active exploration:

- EthicalRenderGate
- meaning-native rendering
- accountable rendering
- restoration metrics
- attention-aware infrastructure
- compiler architecture
- memory graph systems
