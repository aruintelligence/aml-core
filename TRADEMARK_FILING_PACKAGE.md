## Filing basis decision

For every good/service in every application, select the legally correct basis.

### Section 1(a) — use in commerce

Use only when the mark is actually being used in qualifying U.S. commerce for the identified goods/services and a compliant specimen can be supplied.

### Section 1(b) — intent to use

Use when there is a bona fide intent to use the mark in commerce but qualifying use has not yet begun. Later allegation-of-use filings and fees will be required before registration.

Official basis guidance:

- https://www.uspto.gov/trademarks/basics/application-filing-basis
