# ĀML™ Press & Public Brief

## One sentence

**ĀML™ — ĀRU Meaning Language™ is an open, meaning-native accountability layer for AI-generated interfaces that makes declared purpose, policy, authority, and evidence inspectable before and after rendering.**

## Short description

Modern AI can generate interfaces dynamically, but conventional web stacks do not inherently explain why a machine chose to show a particular element, which policy allowed it, or what evidence remains afterward. ĀML is a working research prototype exploring a new layer between machine intent and human-facing UI: an **AI Interface Firewall™** that can evaluate meaning and policy before rendering and produce independently inspectable receipts and provenance.

ĀML is designed to complement—not automatically replace—HTML, React, Next.js, or existing frontend systems.

## The core proposition

> HTML tells the browser what to display. ĀML tells the system why it deserves to be displayed.

The project asks a broader technical question:

**If AI is increasingly deciding what humans see, should those interface decisions carry inspectable meaning, policy, authority, and evidence?**

ĀML's answer is yes—and the repository contains a working prototype of that idea.

## What the public repository contains

The public implementation includes parsing and semantic structures, deterministic policy decisions, accessibility/consent/privacy-oriented controls, execution receipts, cryptographic verification, provenance, audit structures, protocol and schema work, RFCs, conformance fixtures, browser bridges, GitHub Actions integration, enterprise pilot material, and independent-verification tooling.

## What ĀML does not claim

ĀML should be evaluated on reproducible technical behavior, not hype. The project does **not** claim that:

- ĀML is already a ratified Internet or web standard;
- its current attention/restoration inputs are objective measurements of cognition or wellbeing;
- a prototype policy guarantees ethical outcomes;
- cryptographic integrity proves that an underlying human-impact judgment is correct;
- existing browsers or web frameworks must be discarded.

Those boundaries are intentional. The project is trying to make a new class of interface accountability technically testable.
